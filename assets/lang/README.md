# The editor's languages

Each `.json` file here is one language of the editor's windows:

```json
{"language": "Español", "by": "your nick", "words": {"Apply changes": "Aplicar cambios"}}
```

Make one: Tools > Settings... > Language of the window > **Words to translate...** writes every word of the
windows with an empty translation beside each; fill them, put the language's own name in `language` and yours in
`by`, then **Add a language file...** shows it at once. Send the file (a report, Discord) to have it come with the
editor. A word left empty stays English.
