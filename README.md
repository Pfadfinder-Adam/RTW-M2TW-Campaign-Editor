# <img src="assets/icon_256.png" width="64" alt="" align="top"> RTW & M2TW Campaign Editor

**A campaign editor for Rome: Total War (with REX) and Medieval II: Total War (with M2EX).** Factions, the map,
towns, armies, characters, units, buildings, diplomacy, texts and pictures - all in one window, no digging through
files. Every change is shown before it is written, and a backup lets you go back. Free. Version **0.35.4**.

## 🚀 Get started

1. **Download** `RTW-M2TW-Campaign-Editor.exe` from [Releases](../../releases) - only from there, never a copy from
   another site or a chat. No install needed.
2. **Put it into the game's folder**, next to `RomeTW.exe` / `medieval2.exe` (and REX or M2EX, if you have them).
3. **Start it** and pick the game or the mod you build on.
4. **New mod folder...** - your work goes into a folder of its own, the game stays clean.
5. **Change something**, press **Preview changes**, then **Apply changes**.
6. **Start the game** with the green button. Didn't like it? **Undo this write** or **Tools > Restore a backup**.

Windows may warn about the exe because it is not signed yet: *More info > Run anyway*. Linux, macOS or Python:
see [Installing](../../wiki/Installing).

## 🧩 Works with

| Game | Original exe | With the engine |
|---|---|---|
| **Rome: Total War** (Gold / Steam), **Barbarian Invasion**, **Alexander** | works, the game's own limits apply (21 factions, 200 regions...) | **REX** - no limits, wastelands, add-ons, your own modules |
| **Medieval II: Total War** and Kingdoms | works, the game's own limits apply | **M2EX** - the same |

Any mod of these games loads - a big one like HLR or a small one that only changes a few files.

## 🧰 What you can do

| Area | What you do there |
|---|---|
| **Factions** | make a new one from another faction or edit one: names, colours, money, towns, leader and heir, garrisons, buildings, diplomacy, victory |
| **Campaign map** | drag towns, armies and fleets; paint regions, terrain, climates, rivers and heights; a climate library (what each climate gives, new climates); grow, cut or make the map 3 x bigger; see it in 3D |
| **Units and buildings** | every line as a field; new ones step by step; models in 3D, swapped or your own; voices; bring them from another mod |
| **Characters** | traits, retinue, ages, names, the family tree, portraits |
| **Pictures** | every picture of a faction replaced or recoloured, emblem and banners made |
| **Rules and scripts** | every campaign setting in plain words; ready add-ons; your own scripts made of blocks, like Scratch |
| **Safety** | your own mod folder, preview, backups with Restore, Undo / Redo, Check mod files |

Everything in detail: [Every feature](../../wiki/Every-feature) · how each window works: [Reference](../../wiki/Reference).

## ⚠️ Something went wrong?

Press **Report a bug / Suggest** (bottom right). It sends the logs in one click - no account, your names cut out
first - and the answer comes back right in the editor. Please add a screenshot or a short video.
More: [Reporting a bug](../../wiki/Reporting-a-bug).

## Code signing policy

Windows release builds are to be signed through the SignPath Foundation (application pending; until then the exe is unsigned):
free code signing provided by [SignPath.io](https://about.signpath.io/), certificate by [SignPath Foundation](https://signpath.org/).

- Only builds made by this repository's GitHub Actions release workflow from its own source are signed.
- Committers and reviewers: [Pfadfinder-Adam](https://github.com/Pfadfinder-Adam). Approver (every signing request): [Pfadfinder-Adam](https://github.com/Pfadfinder-Adam).

Privacy: this program transfers nothing to other networked systems unless you press **Send** in *Report a bug / Suggest* (then only what that window shows); after that it asks, by the reports' numbers only, for the author's answers to them (on start every few hours - off in Tools > Settings > Reports), and asks GitHub for the number of the newest release (on every start and every 6 hours while it is open; nothing is sent - off in Tools > Settings > New versions). It reads and writes only the game or mod folder you load and its own files beside the exe (`CampaignEditor_settings.json`, `CampaignEditor_logs`, `CampaignEditor_addons`) (see [SECURITY.md](SECURITY.md)).
